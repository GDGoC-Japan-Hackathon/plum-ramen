# plum-ramen
ハッカソンチーム: 梅ラーメン

# 開発
## コンテナを起動する(初回)(requirements.txtを変更した場合はこっち)
```bash
docker compose up --build
```
## コンテナを起動する(２回目以降)
```bash
docker compose up
```
## コンテナを停止する
```bash
docker compose down
```
